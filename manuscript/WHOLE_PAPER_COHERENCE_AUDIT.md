# Whole-Paper Coherence Audit

Read in order: `ABSTRACT.md` → `INTRODUCTION.md` → `RELATED_WORK.md` →
`METHODS.md` → `RESULTS.md` → `DISCUSSION.md` → `CONCLUSION.md`. Verdicts:
**PASS** · **WARN** (minor, wording) · **BLOCKER** (must fix). No science,
number, endpoint, or claim status was changed by this audit; where a fix touched
Methods/Results it would be flagged as a contradiction — none was.

| check | verdict | finding |
|---|---|---|
| **A. Research question** | **PASS** | All seven sections describe the same problem: how retrieval reliability changes as a query target is pushed from exact local attention into compressed recurrent memory. Abstract ("how reliability changes as information comes under increasing memory pressure"), Introduction (the what/when/how framing), Methods (RQ/hypotheses), Results (hypothesis order), Discussion (§4.1–4.4 what/when/how), Conclusion (what/when/how) are mutually consistent. |
| **B. Terminology** | **WARN** | One real split: **`information type` vs `fact type`** for the identical construct. Abstract, Introduction, Related Work, Discussion, Conclusion, and the Results §3.2 heading use *information type*; Methods §2.2 (and its table) and the Results body use *fact type*. Not contradictory, but a reviewer could ask whether they differ. **Recommendation (for the compression pass, not this task):** standardize to *information type* everywhere, keeping "(the design code and released data use the key `fact_type`)" once in Methods. All other flagged terms are consistent: *memory pressure*, *strict production accuracy* (defined in Methods, then "strict accuracy" as an established shorthand), *recurrent/compressed memory*, *compound-relational*, *W*, *K*, *transition region/interval*, *deep recurrent pressure*, *abstention*, *unsignalled failure*, *behavioural uncertainty signalling*. Minor: "exact attention" / "exact local attention" / "exact-attention window" are used interchangeably — same concept, acceptable, but pick one in compression. |
| **C. W vs K** | **PASS** | W = architectural exact-attention window (256); K = empirical performance knee (isotonic 0.5-crossing). Every section that mentions both states K < W. No section implies K = W or K = compression onset. Grep of the seven manuscript files for "K = W", "compression begins", "compression onset", "compression threshold" → only disavowals (Discussion) and none in Abstract/Intro/RW/Conclusion. |
| **D. Degradation framing** | **PASS** | Every section that discusses degradation scopes it to end-to-end task performance and disavows the representational reading. Abstract "End-to-end task-performance degradation"; Introduction "degradation … refers to end-to-end task performance … not a direct measurement of hidden-state contents"; Methods §2.3 "measures end-to-end task performance and does not separate loss of the stored value from a tendency to abstain"; Results §3.2 interpretation; Discussion §4.1; Conclusion "a statement about task performance rather than about how much of a stored value remains in the model's state". |
| **E. H2 transition** | **PASS** | Transformer = earlier + narrower; AHN = later + broader — stated consistently in Abstract ("later and … broader rather than a simple rightward shift of the control's sharper collapse"), Introduction ("later … and … also broader"), Results §3.3, Discussion §4.2, Conclusion ("its accuracy transition is also broader … reshapes the transition rather than translating a sharp cliff"). "AHN has a sharper transition" appears nowhere. Post-freeze status of the width comparison is visible in Abstract, Introduction, Results §3.3 [R22], Discussion §4.2, and Conclusion. |
| **F. Deep-recurrent result** | **PASS** | Production-retrieval failure is kept distinct from latent-information absence in every section that states it: Abstract ("does not establish that the recurrent state lacks the information"), Introduction §P6 (production-evaluation wording), Results §3.5 (approved sentence), Discussion §4.3 ("does not establish that the recurrent state contains no target information"), Conclusion ("does not establish that the recurrent state holds no latent target information"). |
| **G. H3 framing** | **PASS** | Treated as behavioural everywhere. Abstract "a difference in failure mode, described behaviourally"; Introduction "This last result is behavioural: it describes what the model emits, not an internal state"; Related Work §2.3; Discussion §4.4; Conclusion "We describe this as behavioural uncertainty signalling" + "we do not claim that the model internally detects forgetting". No "knows / aware of forgetting / detects forgetting / uncertainty encoded in the recurrent state" outside explicit disavowals. |
| **H. Causality** | **PASS** | Grep for `causes`, `because of`, `due to`, `produces`, `enables`, `allows`, `results from`, `explains` across the seven files: (i) "produce(s) … output" (Introduction, Conclusion) = describing what a model emits, observational; (ii) "attributes … failures to distinct causes" (Related Work) = describing the cited paper's finding; (iii) "explain why a bounded recurrent state has … decaying recall … not to mechanistically explain" (Related Work) = describing MemMamba, plus our explicit disavowal. The AHN-vs-control contrast is described as observational throughout (Methods §2.4 "confounds a recurrent state with the AHN distillation recipe"; Discussion §4.2/§4.4; Conclusion "the architecture contrast confounds the presence of a recurrent state with the AHN training and distillation recipe"). No unwarranted causal claim. |
| **I. Novelty** | **PASS** | Grep for `first`, `novel`, `unique`, `unprecedented`, `state[- ]of[- ]the[- ]art` in Abstract/Introduction/Related Work/Conclusion → zero. Related Work closes with "This study brings these lines together", not a priority claim. |
| **J. Fact-type terminology** | **PASS** | `compound-relational` is the manuscript-facing term everywhere it appears (Introduction, Methods, Results, Discussion). It is disavowed as multi-hop reasoning in the Introduction ("not multi-hop reasoning over separated facts"), Methods §2.2, and Results §3.6. The Abstract and Conclusion do not name it individually and make no multi-hop claim. |
| **K. Numerical consistency (outside Results)** | **PASS** | Abstract: "92,160 trials" = R1; "+0.249, 95% CI [0.233, 0.266]" = R14; "empirical performance knee lies below the architectural window for every architecture" = R17. Introduction previews (no standalone figures beyond these). Conclusion carries no hard numbers ("far larger than label-permutation chance" = R7 qualitatively; "a substantial fraction … inside the lossless window" = R46 qualitatively). Discussion figures were checked in the Discussion hostile review. Every out-of-Results number agrees with `RESULTS_TRACEABILITY.md`. |
| **L. Claim strength (Abstract/Conclusion vs Results/Discussion)** | **PASS** | Abstract adjectives ("strongly information-type dependent", "substantially higher strict accuracy", "essentially absent", "predominantly abstain") each match a register-allowed phrasing (H1-1, H2-1, H2-5, H3-1). The Abstract states "their transition occurs later and … is broader" as fact but flags the width comparison as post-freeze. The Conclusion's strongest sentence ("the dominant observed distinction … is failure behaviour") matches Discussion §4.4 verbatim in substance. Neither the Abstract nor the Conclusion is stronger than Results/Discussion. |
